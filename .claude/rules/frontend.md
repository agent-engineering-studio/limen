# SPA, niente login, palette, attribuzione Copernicus, token di installazione

Testo completo degli invarianti di cui `CLAUDE.md` tiene solo la riga breve:
la regola e il perché (misure, incidenti, issue). Vincolanti quanto la tabella.

| Topic | Rule |
|-------|------|
| Frontend = Vite (no Next.js), and **no user auth** | Phase 6 ships a public read-only map. Vite + React + MapLibre is the right surface; Next.js adds an unneeded Node server / RSC overhead. There is **no authentication** (epic #69): the whole SPA — map, national strip, alerts, comuni, shadow diagnostics — opens without a login, because the APIs feeding it were always public and a login protected the page, not the data. The privileged actions are two: launching a sweep, on the CLI (`limen monitor-once`) and on MCP behind `MCP_ADMIN_TOKEN`; and queueing a static-data download from `#/installazione`, behind `INSTALLAZIONE__TOKEN` (see «The install token is not a login»). Do not reintroduce a login for a hypothetical operator area — that is the future-proofing this file forbids; #49's work is recoverable from git if the need becomes real. |
| Risk palette: one ramp, **not colour-only**, verified on the dark ground | Sala operativa (#155): one five-class ramp for all three hazards (nessuno quasi-fondo, basso petrolio, giallo, arancio, rosso — the Protezione civile order). The legend pairs every colour with the Italian label and the score range. `risk-colors.test.ts` enforces that **every pair** of classes stays ≥ 1.5:1 in luminance contrast, painted at 70 % over the dark basemap, under normal vision and Machado deuteranopia/protanopia/tritanopia — the design's own ramp failed it (1.09:1). Change a colour ⇒ the test says whether it still holds. Hazard identities (lilla/ciano/rosa, `HAZARD_HUE` = `--hz-*`) stay out of the ramp's warm hues. |
| The install token is not a login | `INSTALLAZIONE__TOKEN` (#403, epic #409) gates the actions of `#/installazione` that **change** something — `POST /api/installazione/*`, i.e. queueing a download for the worker, or re-running the load of the downloaded files into the cells — through `TokenInstallazioneDep` (header `X-Limen-Token`, constant-time compare, never logged). Reading the state (`GET /api/installazione/stato`) stays public like the rest of the map. Same scheme as `MCP_ADMIN_TOKEN`: one shared secret in the `.env`, generated by `nuovo_host.sh`; **no users, no sessions, no personal data**, unset ⇒ actions disabled (fail-closed). It does not reopen epic #69: do not grow it into accounts, roles or an operator area. |
| Copernicus attribution stays | The CEMS-Floods licence (GloFAS/EFAS) asks whoever publishes derived data to say «Contains modified Copernicus Emergency Management Service information [Year]» and never to present it as a flood warning. The notice lives in `frontend/src/lib/attribuzioni.ts` (map source for flood and the multi-hazard view, home footer, flood articles in Verifiche) and `report/regioni_pdf.py` (page footer). A new surface showing flood scores gets it too; removing it breaks the licence, not a style rule. EWDS credentials are `CDSAPI_URL`/`CDSAPI_KEY` in `.env` (read by `cdsapi` and earthkit), never in the repo. |
